# Agrinho.revolucionario-

1. Mais perguntas;
2. O jogo trava na mesma pergunta;
3. A pergunta fica por quase 15 segundas depois de acertar;
4. adicionar uma chuvinha de moedas que representam os pontos toda vez que pega uma planta;
5. aumentar a velocidade conforme for avançando;
6. coletar um numero X de plantas para desbloquear a proxima fase;
7. juntando moedas e plantas você pode desbloquear recursos para a fazenda (solo);
8. fugir de uma big praga;
9. se a praga te pegar você tem que responder 3 perguntas para reviver, se errar perde tudo e o jogo reinicia;
10. adicionar pragas e obstaculos para ficar mais dificil;
11. duplicador de pontos, 15 segundos na tela;
12. pedaços de solo arenoso;
13. desviar de máquinas como: Trator de esteira, Enxada rotativa
